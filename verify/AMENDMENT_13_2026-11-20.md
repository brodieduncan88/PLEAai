# Amendment 13, 20 November 2026

Private working material. Times are UTC.

This is internal work by the author of the code, under the owner's direction. It is not an independent validation.

## What it repairs

Every answer the front door gave took longer than the one before: about 0.05 s more for every run already made on the
baseline. Thirty designs in a row took 0.49 s for the first and 1.97 s for the thirtieth; a baseline with a thousand runs
would have taken about 50 s for an answer. This was found while looking for the cause of F17's failure in the official run
of Amendment 12 (`verify/DIAGNOSTIC_F17_2026-11-19.md`, on the branch `diagnostic-f17-2026-11-19`). It is not in the sandbox.
`DECLARED_AMEND13.md` states the change, the expected outcomes, the development work and what stays open.

In short:

- **The cause.** After every verdict the front door reads the baseline's runs, to count them in its answer. That reading
  (`attempts_of`, in `verify/verify_record.py`) read each run by itself, through five connections to the database of its
  own.
- **The change.** It reads the budget's evidence, receipts and results in one transaction on one connection: two
  connections for a reading, whatever the number of runs. What it gives is the same. Only `verify/verify_record.py` is
  changed; the gateway is not.
- **R28**, new, in the gate's suite, shows that: the same number of connections for 15 runs as for 3, and exactly what
  reading each run by itself gives, also for an interrupted run, a run with two reports, a reading cut at an earlier
  decision, and beside another budget's rows for a run of the same name.
- **F36**, new, in the front door's suite, times 25 answers in a row: the last five must be less than a quarter of a second
  slower than the first five.

## F17 is not repaired by this

F17 passed here because an answer is now a little quicker, and no longer slows from one try to the next. It still makes its
case by two runs ending within one second, with a few hundredths of a second to spare. Its failure in the official run of
Amendment 12 stands as it was reported. Restating F17 so that it checks for itself whether its case was made is the next
amendment, and so is the correction of one sentence of Amendment 12's amendment, which says a run "takes about a second"
when F17 fails: no run did.

## What changed on the way

The change itself did not change after it was first made. An independent review of it, by a separate agent that read the
code and the store's tables and ran no test, reported nothing of medium weight: the reading is the same for every caller,
no row can be read twice or lost, and every role holds the grant it needs. It reported that R28's docstring claimed more
than R28 shows, that R28 read no interrupted run, and that F36, a test of time, can be wrong both ways.

R28 went through three forms. A first pass of nine deliberate defects caught seven: R28 could not see an attempt's reports
read out of order, since each run it read had one, nor the reports of every budget read in place of this one's, since no
other budget held a run of the same name. It was made to read both; a second pass caught eight, because the other
budget's report had been put where a reading never looks, and because R28 stopped with an error where it should have
failed a check; the third caught all nine, and the control passed each time. The last two forms of R28 were read only by
their author.

## What stays open

The declaration's "What stays open" section is the full list. The main items are:

- An answer still does work that grows with the runs already made: every reading moves every row of the budget and reads
  the whole journal, and the governor and the witness read the budget's state for every run. None of it showed over 30
  runs. What it comes to at thousands was not measured.
- F36 measures time. It can fail where nothing grows, and it passes a growth of less than about 0.0125 s for each run. R28
  depends on no clock.
- The store still opens a connection for every call. Other code that calls it once for each of many things would slow in
  the same way.
- F17, above.
